### 📌 게임 설명


### Scene. 메인

- 시작하기 > 처음부터 게임 시작
- 미니게임탭에서 다양한 미니게임을 할 수 있다.
- 설정: 효과음, 배경음 조절/ 코드 입력
<br>

### Scene. 상점
- 현재 재화량, 스킨 표시
- 스킨 목록(이름, 외형, 가격) 표시 (DB에서 관리)
- 구매 시 DB의 유저 인벤토리,재화량 업데이트 & 자동 장착
<br>


### Scene. 플레이
- 클라이언트간 아이템 상호작용
  - 해씨 공격!: 화면에 리듬게임이 뜨고 성공시 대쉬발동, 실패시 스턴상태가 된다.
  - 아름다운 풀밭: 화면 전체를 가리는 풀밭이 일정시간동안 활성화된다.
  - 달려 달려!: 대쉬 발동
  - 방어막!: 방어막 활성화되어 있는 동안 상대의 아이템 공격을 무효화 한다.(1회)
- 타일 별 속도 조절(풀밭에서는 느려진다.)
- 상대 골인 후 10초안에 들어오지 않으면 리타이어, 승리시 +100해씨, 패배 또는 리타이어시 +50해씨 획득
<br>

##### 🎯 게임 개요

**Kana Rebuild**는 손상된 AI 시스템을 복원하는 코딩 퍼즐 게임입니다.  
터미널 인터페이스에서 코드 오류를 찾아내고, 제한 시간 내에 정답을 선택하여 동기화 게이지를 채워야 합니다.

###### 🎮 게임플레이
- **4개의 스테이지**: 점진적으로 어려워지는 코딩 문제
- **시간 제한**: 스테이지당 10초의 여유 시간, 이후 1초마다 **-5% 페널티**
- **동기화 게이지**: 정답 시 **+25%**, 오답 시 **-50%** (2번 틀리면 위험!)
- **애니메이션**: 각 상황에 맞는 캐릭터 영상 (Normal, Correct, Wrong, Death, Ending)

###### 💀 난이도
- **오답 허용**: 단 2번
- 10초 후부터 지속적인 게이지 감소
- 게임오버 시 자동 재시작

##### ✨ 주요 기능

###### 🎬 영상 시스템
- **상황별 연출**: 스테이지별 4가지 영상 (Normal, Correct, Wrong, Death) 연동
- **전환 효과**: 정답 제출 후 부드러운 하얀 페이드(White Fade) 전환
- **최종 보상**: 게임 클리어 후 전용 엔딩 영상 재생

###### 🖥️ 터미널 UI
- **몰입감**: 실시간 타이핑 효과 구현
- **자동화**: 로그 출력에 따른 스크롤 자동 조정
- **디자인**: 실제 개발 환경과 유사한 터미널 스타일 로그 출력

###### 📊 동적 게이지 시스템
- **상태 시각화**: 실시간 동기화 게이지 표시
- **피드백**: 양수/음수 게이지 변화 시각화
- **경고 알림**: 페널티 발생 시 깜박임 효과 적용

###### ⏱️ 타이머 시스템
- **연속 타이머**: 스테이지당 연속적인 타이머 (오답 시에도 초기화되지 않음)
- **시간 페널티**: 10초 후부터 지속적인 게이지 감소 적용
- **조건부 정지**: 정답을 맞췄을 때만 타이머 일시 정지
